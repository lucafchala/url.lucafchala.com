# url.lucafchala.com

> The public directory of every short link (PURL) in the `lucafchala.com` network, plus a quick-launch grid of the ecosystem's pages.

**Live:** [url.lucafchala.com](https://url.lucafchala.com) · **Stack:** static HTML/CSS/JS on Cloudflare Pages · **Build step:** none

Part of the [lucafchala.com ecosystem](https://github.com/lucafchala/lucafchala.com#the-ecosystem). Design system, conventions and the data flow: [hub README](https://github.com/lucafchala/lucafchala.com#readme).

---

## What it is

The redirecting itself (`/<slug>` → destination) is done by Cloudflare Pages from `_redirects`, identical here and on `lucafchala.com`: every link works at both `lucafchala.com/<slug>` and `url.lucafchala.com/<slug>`. This page exists so people can **browse, search and copy** those links.

**Almost every file here is generated and committed by [`dash`](https://github.com/lucafchala/dash.lucafchala.com)**; this repo is an output target.

| File | Generated by (in dash) | Notes |
|---|---|---|
| `index.html` | `genUrlIndex(items)` | The full list is **baked into the HTML** — no fetch, works without JavaScript, crawlable |
| `url.js` | `genUrlJs()` | Theme/lang, filter, copy, `#group` deep links, `/` shortcut |
| `data.json` | `genDataJson(items)` | Same data as the dash; read by the 404 page's suggestions and by the status monitor |
| `_redirects` | `genRedirectsFile(items)` | `/<slug>  <dest>  302` (301 only for links marked permanent) |
| `404.html`, `404.js` | `gen404Html()`, `gen404Js()` | Same pair as lucafchala.com: PT/EN, decoded slug in a toast, "did you mean" suggestions |

Each generated file starts with a `generated by dash.lucafchala.com (genX)` marker. **Hand edits are overwritten on the next save in the dash** — change the generator there instead.

Hand-owned files: `README.md`, `CLAUDE.md`, `_headers`, `robots.txt`, `icon.svg`, `fonts/`, `.github/workflows/checks.yml`.

## Features

- Links grouped by `contact`, `events`, `video`, `tools` in native `<details>` sections (keyboard accessible without JS; `events` and `video` start collapsed).
- **Filter** box: matches slug and destination, opens matching groups, restores them when cleared, shows "N of M". Press `/` to focus it.
- **Copy** puts the canonical short link `https://lucafchala.com/<slug>` on the clipboard, with a fallback for non-secure contexts and an `aria-live` confirmation. **Open** goes straight to the destination.
- **Deep links:** `url.lucafchala.com/#events` opens and scrolls to that group.
- PT/EN and dark/light, shared with every `*.lucafchala.com` site (`lf_lang` / `lf_theme` cookies).
- Meta description, canonical and Open Graph tags; no horizontal scrolling at 360 px; axe-clean in both themes.

## Architecture

- **Host:** Cloudflare Pages; the dash's commits trigger deploys.
- **CSP:** `script-src 'self'`, `font-src 'self'` (self-hosted fonts), `connect-src 'self'`, `object-src 'none'`, COOP/CORP. There are no inline scripts or handlers.
- **Headers:** `/data.json` is served with `Access-Control-Allow-Origin: *`, so the 404 page on lucafchala.com can read it for suggestions.

## CI (`.github/workflows/checks.yml`)

- JSON validity, weak-escaper grep, `_headers` present, `node --check`.
- No inline scripts / `on*=` handlers.
- **Generated files agree with each other:** every generated file carries the dash marker, and every link in `data.json` appears in `_redirects` with the right destination and status and is listed in `index.html`.
- **Weekly drift job** (scheduled only): `_redirects` must equal lucafchala.com's. It doesn't run on PRs, because while PRs for both repos are open the other repo's `main` is legitimately behind.
